# JobForge

AI-powered job application tracker built with FastAPI, React, PostgreSQL, and the Anthropic Claude API. Features JWT authentication, resume tailoring, ATS match scoring, and interview prep generation. Deployed on AWS with Docker and CI/CD via GitHub Actions.

## Stack

**Backend:** Python · FastAPI · PostgreSQL · SQLAlchemy · Alembic · JWT Auth  
**Frontend:** React · TypeScript · Tailwind CSS · Vite  
**AI:** Anthropic Claude API  
**Infrastructure:** Docker · AWS (S3, RDS, Lambda) · GitHub Actions CI/CD
